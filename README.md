# 👤 Face Recognition System

A Python-based Face Recognition System that detects and recognizes human faces using Machine Learning and OpenCV. The project can be trained on image datasets and used for real-time face recognition through a webcam.

## 🚀 Project Overview

This system performs the following tasks:

* Face Detection using Haar Cascade Classifier
* Training a face recognition model using image datasets
* Real-time face recognition through webcam input
* Prediction of known faces from live video feed

## ✨ Features

* Face detection from images and webcam
* Face recognition using a trained model
* Real-time prediction
* Simple and easy-to-use implementation
* Built using Python and OpenCV

## 🛠 Technologies Used

* Python
* OpenCV
* NumPy
* Machine Learning
* Haar Cascade Classifier

## 🎯 Applications

* Attendance Management Systems
* Access Control Systems
